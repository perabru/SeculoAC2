# SeculoAC2

Abra o projeto no Unity 2021.3.37f1, carregue `Assets/Scenes/Fase1.unity` e pressione **Play**. A Fase1 também é a cena inicial da build.

## Controles

- **A/D** ou **←/→** para mover.
- **Espaço** para pular. No ar, pressione **Espaço** junto a uma parede para saltar para longe dela.
- Segure a direção da parede durante a queda para deslizar mais devagar.
- **J** ou **Z** para atacar. **Shift esquerdo** para dar um dash.

O jogador tem cinco pontos de vida. O inimigo fica amarelo pouco antes de atacar. Saia do alcance para evitar o golpe. Três ataques do jogador derrotam o inimigo. Ao perder toda a vida ou cair do cenário, o jogador volta ao ponto inicial com a vida cheia.
